# AirSim VLN 规划器

用一句话指挥仿真里的无人机或无人车：它会看着画面找目标、自己规划路线、飞过去或开过去。

打开浏览器选一张地图，页面上是引擎的实时画面和一条指令输入框。输入「开到前方那辆红色汽车旁」，
服务把这句话拆成有先后顺序的几步，让视觉模型在画面里找到目标，规划出接下来的几个落点，控制载具一步步执行；
途中可以随时停下，剩余路线、日志和画面都在同一个页面里。

这套东西同时支持两代 AirSim 仿真器：基于虚幻 5 的 ProjectAirSim，和基于虚幻 4 的经典 AirSim。

## 能做什么

| 你说的话                     | 它做的事                                                     |
| ---------------------------- | ------------------------------------------------------------ |
| 向前直行五米，然后左转九十度 | 按距离和角度走完每一步，停稳后报告完成                       |
| 向前飞行十米，再上升五米     | 同上，加上升降                                               |
| 开到前方那辆红色汽车旁       | 在画面里认出目标，分批规划落点，根据所选配置执行并判定到达   |
| 沿着这条路一直开，遇障绕开   | 持续沿路巡航，碰到障碍会退一点、重新看、继续；要你叫停才结束 |

在「规划设置」里可以选择两种视觉目标导航方式。「世界模型」由规划器校验航点并控制载具，到达后让模型查看画面确认是否完成。「普通 VLM」根据指令和前视图像生成航点，交给仿真器跟随，再按载具与目标的实测距离判定到达。见[视觉目标导航的执行方式](docs/ARCHITECTURE.md#视觉目标导航的执行方式)。

## 界面

| 控件                 | 作用                                                             |
| -------------------- | ---------------------------------------------------------------- |
| 世界设置标签页       | 选地图、启动与停止场景；换图会重启引擎，天气与当前机位带到新场景 |
| 天气标签页           | 八种参数与预设，两套仿真器都有                                   |
| 模型标签页           | 车型清单，虚幻 5 独有                                            |
| 规划设置标签页       | 换配置；场景已启动时重载场景，约 8 到 10 秒                      |
| 机位按钮             | 在四台相机之间循环，虚幻 5 独有                                  |
| 指令框右侧的 ☰ 竖栏 | 从预设指令里挑一句填进输入框；清单在 `console/presets.json`      |

## 支持的场景

| 地图                                                         | 引擎                    | 可操控的载具    | 可用任务                           |
| ------------------------------------------------------------ | ----------------------- | --------------- | ---------------------------------- |
| 城市、郊区、交流中心                                         | ProjectAirSim（虚幻 5） | 无人机 + 无人车 | 按距离动作、目标接近、沿路巡航     |
| 郊区 NH、废弃公园、MSBuild 园区、TrapCam、Blocks、上海、校园 | AirSim（虚幻 4）        | 无人机          | 按距离动作、目标接近、飞向目标顶面 |

能力来自仿真器实现的接口，`/api/status` 的 `capabilities` 列出当前场景开了哪些。

## 跑起来

准备 Linux + NVIDIA 驱动、Xvfb、xpra 和两套引擎的打包产物。命令都在仓库根目录执行。

1. 装两套 Python 环境。主环境跑服务与虚幻 5 会话，另一个环境跑虚幻 4 任务子进程。

   ```bash
   sudo apt install -y xvfb xpra x11-utils
   conda create -n vln python=3.11 -y && conda activate vln
   pip install -r requirements.txt && pip install --no-deps projectairsim==1.0.2
   conda create -n vln-ue4 python=3.11 -y && conda activate vln-ue4
   pip install -r requirements-ue4.txt
   pip install --no-deps --no-build-isolation airsim==1.8.1
   ```

2. 填机器相关的配置：`config/maps.yaml` 的 `root` 指向引擎包目录，
   - `config/simulators.yaml` 的 `airsim.runtime_python` 指向 `vln-ue4/bin/python`。
   - `config/core/default/base.yaml` 里四段模型端点默认指向 `api.deepseek.com/anthropic`，换 provider 改这四段。
     密钥从环境变量读：
     ```bash
     export VLN_API_KEY='你的密钥'
     ```

3. 启动服务。`Ctrl-C` 停服务时会一并关掉本服务拉起的仿真栈。

   ```bash
   conda activate vln && python scripts/serve_planner.py --host 0.0.0.0 --port 8000
   ```

4. 打开 `http://<主机>:8000/`，在「世界设置」选图并点「启动场景」，状态变为就绪后画面接上。
   选无人机或无人车，输入指令提交；用完点「停止世界」关引擎，服务本身继续跑。

## 设计取向

| 做法                             | 原因                                                                             |
| -------------------------------- | -------------------------------------------------------------------------------- |
| 画面和控制走同一条会话           | 一台仿真器同时服务一个客户端，你看到的画面和你能下发的指令作用在同一份世界状态上 |
| 换地图时整套重启                 | 一个引擎进程加载一张地图。画面会短暂断开再自动接回，换来干净的世界状态           |
| 画面里同时显示一台载具           | 另一台被移到地图上方高空，两台车错开位置，四个机位各自拍到不同画面               |
| 固定四个机位（虚幻 5）           | 四个预设机位让切换对得上，自由观察看 xpra 画面本身                               |
| 停止在当前动作边界生效           | 正在执行的那一段立即中止，下一条指令从当下状态开始                               |
| 模型参与解析、目标检测与轨迹规划 | 四个模型端点可以分别配置                                                         |
| 虚幻 4 的任务跑在子进程里        | 它的客户端库与虚幻 5 撞同一个模块名，两套各装一个解释器                          |
| 服务默认监听本机                 | 要公网访问，前面加一层反向代理和鉴权                                             |
