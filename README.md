# AirSim VLN 规划器

用一句话指挥仿真里的无人机或无人车：它会看着画面找目标、自己规划路线、飞过去或开过去。

打开浏览器选一张地图，页面上是引擎的实时画面和一条指令输入框。输入「开到前方那辆红色汽车旁」，
服务把这句话拆成有先后顺序的几步，让视觉模型在画面里找到目标，规划出接下来的几个落点，控制载具一步步执行；
途中可以随时停下，剩余路线、日志和画面都在同一个页面里。

这套东西同时支持两代 AirSim 仿真器：基于虚幻 5 的 ProjectAirSim，和基于虚幻 4 的经典 AirSim。

## 能做什么

| 你说的话 | 它做的事 |
|---|---|
| 「向前直行五米，然后左转九十度」 | 按距离和角度走完每一步，停稳后报告完成 |
| 「向前飞行十米，再上升五米」 | 同上，加上升降 |
| 「开到前方那辆红色汽车旁」 | 在画面里认出目标，规划五个落点，边接近边修正，到了停下并确认 |
| 「沿着这条路一直开，别撞上东西」 | 持续沿路巡航，撞到东西会退一点、重新看、继续；只有你叫停才结束 |
| 「切到郊区那张图」 | 换地图、换场景，天气自动恢复 |
| 「换成六旋翼」 | 只重载场景，不重启引擎 |
| 「下雨、起雾」 | 八种天气参数，带预设 |
| 「看车头 / 看车尾 / 看机头 / 看机尾」 | 在四个固定机位之间切换 |

同一时刻只显示一台载具。点「无人机」或「无人车」就等于切换并归位：另一台被移出视野、保持在空中，
选中的这台回到出生点，画面跟着切到它的后方。

## 支持的场景

| 场景 | 引擎 | 可操控的载具 | 可用任务 |
|---|---|---|---|
| 城市、郊区 | ProjectAirSim（虚幻 5） | 无人机 + 无人车 | 按距离动作、目标接近、沿路巡航 |
| 街区、校园、园区等 | AirSim（虚幻 4） | 无人机 | 按距离动作、目标接近 |

哪台引擎能做哪些事不是开关，而是由它实际实现的功能决定的，页面上的按钮会跟着变。

## 跑起来

准备一台有显卡的 Linux 机器，装好 Xvfb 与 xpra，以及两个引擎的打包产物。服务不编译引擎、不打开编辑器，
只负责把打包好的可执行文件拉起来。

1. **装依赖。** 需要两个 Python 环境：主服务加虚幻 5 客户端一个，虚幻 4 客户端另一个。
   两套客户端库在同一个环境里会互相覆盖，这一点在[部署文档](docs/DEPLOYMENT.md)里说清了原因。
   ```bash
   python -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   pip install --no-deps projectairsim==1.0.2
   ```
2. **登记地图。** 打开 `config/maps.yaml`，把每张地图的引擎可执行文件路径和地图名填上。
3. **配置模型。** `config/base.yaml` 里有四个模型端点：拆解指令、找目标、规划路线、确认到达。
   它们都指向一个兼容 OpenAI 协议的服务，密钥放环境变量 `VLN_API_KEY`。
4. **启动服务。** 服务启动时是空的：没有场景，也没有画面。
   ```bash
   python scripts/serve_planner.py --host 0.0.0.0
   ```
5. **选地图、起场景。** 浏览器打开 `http://<主机>:8000/`，在「世界设置」里选一张图，点「启动场景」。
   几十秒后状态变成就绪，画面自动接上。用完点「停止世界」关掉引擎，服务本身继续跑。
6. **下指令。** 在输入框里写一句话，选择无人机或无人车，提交。

上机前可以先跑两个检查：

```bash
python scripts/probe_ue4_env.py
python -m pytest -q
```

## 设计取向

几条看起来像限制的东西，是有意这样设计的。

**画面和控制是同一条会话。** 一台仿真器同时只服务一个客户端，
好处是你看到的画面和你能下发的指令作用在同一个世界状态上，不会出现页面与现实脱节。

**换地图是一次干净的重启。** 一个引擎进程只加载一张地图，所以换图就是停掉整套再起整套，
画面会短暂断开然后自动接回。换来的是没有上一个场景的残留状态。

**同一时刻画面里只有一台载具。** 另一台被移到地图上方高空并保持在那里。这样两台车不会互相遮挡，
四个机位也各自拍到不同的画面。

**机位是四个固定视角。** 引擎没有自由观察者相机。四个预设机位保证每次切换都能对上，
而真正的自由观察靠 xpra 画面本身——那里可以直接用鼠标和键盘操作场景。

**任务随时可以停。** 停止在当前动作的边界生效，正在执行的那一段立即中止，不会顺延到下一条指令。

**模型是唯一的大脑。** 拆解指令、找目标、规划路线、确认到达都交给模型端点，仓库里不维护第二套规则。
换模型就能换行为，不需要改代码。

**画面端口默认只给局域网。** 需要公网访问时，在前面加一层反向代理和鉴权，别直接暴露。
