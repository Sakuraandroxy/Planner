# 耗时分析

更新时间：2026-07-15。

> 本文档已按当前 AirSim UAV-VLN 主线刷新。当前在线入口是 `run_airsim_web.py`，配置入口是 `config/default.yaml`，离线评测入口是 `eval/run_eval.py`。

## 当前典型耗时

| 项 | 典型耗时 |
|---|---:|
| RGB ready | 0.3-0.4s |
| GroundingDINO | 0.6-1.1s |
| depth parallel capture | 2.6-3.4s |
| Qwen planner | 4-6s |
| completion VLM | 2-5s |
| AirSim execute | 取决于路径长度 |

## 并行策略

`SPLIT_RGB_DEPTH_CAPTURE=true` 时，RGB 到手后立即启动检测和规划，深度图后台返回后再完成判定。因此每步等待不是字段相加，而是并行后的墙钟时间。

## 日志字段

- `cap`: 抓图耗时。
- `det`: 检测/完成判定相关耗时。
- `plan`: planner 耗时。
- `vlm`: 检测与规划模型耗时统计。
- `exec`: AirSim 执行耗时。
- `total`: step 墙钟时间。
