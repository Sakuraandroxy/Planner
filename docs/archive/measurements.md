# 实测数据

参考机器：Linux，无桌面会话，`Xvfb` + 窗口化引擎，NVIDIA RTX 3080 Ti。所有数字来自一次真实运行，
用于换机后对比，不是性能承诺。

## 起图与切换

| 动作 | 耗时 |
|---|---|
| 仿真栈重启 `cityenviron` | 7.8 s |
| 仿真栈重启 `neighborhood` | 7.0 s |
| UE5 起图到 `idle`（含场景与会话装配） | 13.6 s |
| UE4 起图到就绪（`blocks`） | 5 s |
| UE4 起图到就绪（`campus`） | 8 s |
| 停止仿真栈 | 1.4 到 1.8 s，端口释放，无 X 锁残留 |
| 跨族切换 cityenviron → blocks | 8 s |
| 跨族切换 blocks → cityenviron | 40 到 42 s |
| 机位切换在桌面生效 | 2 到 4 s |
| 一次完整机位标定（含不可取帧超时） | 13.8 s |
| 服务 `Ctrl-C` 退出 | 3 到 16 s；任务中要等落地，见过 40 s |

换图耗时是两个尺度：仿真栈本身 7 到 9 秒；操作员等到 `idle` 还要叠上场景装配， UE5 约 40 秒，UE4 约 8 到 16 秒。

### 偏航执行链

UE5 的无人机停止后持续左右摆，只读采样得到的结论：

| 项 | 值 | 采样条件 |
|---|---|---|
| 位置峰峰值 | x 0.000 m、y 0.000 m | 30 s，约 10 Hz |
| 偏航峰峰值 | 11.8°，角速度 ±5 °/s | 同上；摆动只在航向上 |
| `twist.angular.z` 与偏航数值导数 | 比值中位 1.001，符号一致率 100% | 27 s，1862 样本 |
| 摆动周期 | 角速度过零间隔 3.7 s | 同上 |
| 指令峰峰值 | 36 °/s | 反推自实测序列 |
| 实测角速度峰峰值 | 14 °/s | 同上 |

对「指令 → 实测角速度」做一阶加纯延迟拟合，得到等效增益 0.30、时间常数 0.30 s、纯延迟约 3.0 s。
拿这个对象回放闭环：增益 2.0、阻尼 0.6 从偏 10° 出发会发散到 23° 以上，与现场一致；增益 0.4、
阻尼 0 在 4 s 延迟、执行链增益 0.7 下仍不发散。

位姿差分不能做角速度反馈，量过的噪声：

| 采样率 | 差分角速度标准差 | 峰峰值 |
|---|---|---|
| 30 Hz | 10.9 °/s | 42.0 °/s |
| 15 Hz | 2.2 °/s | 40.5 °/s |

## 任务级

| 任务 | 结果 |
|---|---|
| UE5 两阶段数值动作「向前飞三米然后右转九十度」 | 39 s，本地量测确认 |
| UE4 同一句指令 | 25.4 s，位移 3.084 m、偏航 89.81° |
| UE4 单段「向前飞两米」 | 16.1 s；同一引擎接第二个任务 12 s |
| UE4 视觉目标「向前飞到那个红色集装箱前面」 | 60 s 到达，9 次 grounding，每次输入 1155 到 1402 token |
| UE5 视觉目标「前方路面」 | 5.9 s 到达，路径 5.8 m |
| UE5 视觉目标右侧砖楼 | 72.5 s，86.8 m |
| 无人车自由导航 30 s | 行驶 60.3 m，途中两次碰撞退避 3 m / 6 m 后继续 |
| 无人车自由导航（郊区，碰撞修复后） | 171.8 m、13 次规划后撞上真实栅栏 `Fence_250` |
| 停止（任务中） | UE4 实测 2 s 回到 `idle` |

「起飞并向上爬升两米」会被解析器拒绝：基础动作只支持前/后飞与偏航，垂直起飞是会话准备动作。
「上升十米」在基础动作拆分后可以执行，见上表。

## 已知的环境噪音

- `lark-parser` 在 Python 3.11 上打印 `module 'sre_parse' is deprecated`，无害。
- `starlette` 的 `httpx` 弃用告警。
- `pip check` 报 `opencv-python` / `opencv-contrib-python` 未安装，满足它们的是 headless 变体。
- 有一张显卡驱动异常（`Unknown Error`），需要显式绑定健康卡；`torch` 两个环境都没装。
