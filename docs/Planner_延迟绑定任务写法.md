# Planner 延迟绑定任务写法

## 一句话规则

- 想启用延迟绑定：明确写出“以该阶段开始时的当前视野为准”，并使用“当前视野、转向后、前方可见、新视角、下一栋”等词。
- 不想启用延迟绑定：直接使用稳定目标描述，例如颜色、类别、外观、固定地标；不要写“当前视野/转向后/前方可见”。
- 想返回已经访问过的目标：使用“飞回、返回、回到第一次经过的……”等明确返航词。这属于历史记忆返航，不属于延迟绑定。

## 什么时候会延迟绑定

目标阶段满足以下任意条件时，Planner 会把目标标记为视角相关目标，并延迟到该阶段真正开始时重新检测：

- 当前视野、当前视角、当前画面
- 前方可见、可见的第二栋、可见的下一辆
- 转向后、左转后、右转后、掉头后、新视角
- 英文：`current view`、`visible ahead`、`after turning`、`new view`、`next building`

阶段开始时，Planner 会重新抓取当前画面、深度和位姿，然后在这次观测中建立局部目标编号。

例如：

```text
原地左转90度。然后以转向完成时的当前视野为准，飞到前方可见的第二栋高楼旁边并悬停确认。
```

这里的“第二栋高楼”指左转完成后的新视野中的第二栋，而不是任务开始时的第二栋。

## 推荐的延迟绑定写法

### 按当前视野编号

```text
飞到当前视野左侧第一栋白色建筑旁边并悬停确认。
```

```text
飞到当前视野中从左到右第二栋高楼旁边并悬停确认。
```

### 转向后重新编号

```text
先飞到当前视野左侧第一栋白色建筑旁边并悬停确认，原地左转90度，然后以转向后的新视野为准，飞到前方可见的第二栋高楼旁边并悬停确认。
```

### 在建筑间穿梭

```text
飞到当前视野中前方第一栋高楼旁边。原地右转90度后，以新视野为准，飞到当前视野中右侧第一栋高楼旁边。
```

### 推荐加上排序方向

“第二栋”最好同时说明排序方向，避免左右顺序和前后顺序产生歧义：

```text
以当前视野为准，从左到右选择第二栋高楼。
```

```text
以当前视野为准，沿前方飞行方向遇到的第二栋高楼。
```

## 什么时候不会延迟绑定

以下写法通常使用普通任务记忆或启动时扫描，不会因为目标阶段开始而重新建立当前视角编号：

```text
飞到红色汽车旁边。
```

```text
飞到白色仓库附近。
```

```text
飞到任务中看到的第一辆白车旁边。
```

```text
飞到第二栋高楼旁边。
```

最后一个例子只有“第二栋”，没有说明参照视角。它可能被解释为任务记忆中的全局第二个实例，因此不建议在高楼穿梭任务中使用。

如果不想延迟绑定，建议写出稳定的目标特征：

```text
飞到带蓝色玻璃幕墙、位于道路尽头的高楼旁边。
```

```text
飞到有红色屋顶的白色建筑旁边。
```

注意：不延迟绑定不代表目标一定在启动时可见。如果目标初始不可见，Planner 仍可能需要普通重定位，但不会按新视角重新定义“第几栋”。

## 历史目标返航写法

如果目标已经完成过，之后需要回到同一个物理实例，使用明确的返航词：

```text
先飞到左前方第一辆白车旁边，再飞到右前方第一辆红车旁边，最后飞回之前经过的那辆白车旁边。
```

```text
飞回第一次经过的白色汽车旁边并悬停确认。
```

这类阶段会复用已经锁定的实例记忆；当目标位于无人机后方时，Planner 才允许 `MemoryReorient` 原地转向。

不要把“飞回旧目标”和“转向后当前视野中的新目标”混写：

```text
原地左转90度后，飞到第二栋高楼旁边。
```

这句话缺少“以转向后的当前视野为准”，容易和旧目标记忆产生歧义。建议改成：

```text
原地左转90度后，以转向完成时的当前视野为准，飞到前方可见的第二栋高楼旁边。
```

## 如何从日志确认是否生效

延迟绑定生效时，应看到类似日志：

```text
[MemoryBind] view_relative target='tall building' ordinal=2 ...
[MemoryBind] local_instances=[...] primary=...
```

启动阶段不应再把这类目标列入：

```text
[MemoryBootstrap] targets=[...]
```

对于视角相关的新目标，通常也不应看到由旧锁定实例触发的：

```text
[MemoryReorient] target_behind ...
```

## 最推荐的通用模板

```text
完成前一个目标后，执行[左转/右转/掉头]。然后以转向完成时的当前视野为准，选择[左侧/右侧/从左到右/沿前方]的第[N]个[目标类别]，飞到目标旁边并悬停确认。
```

例如：

```text
先飞到当前视野左侧第一栋白色建筑旁边并悬停确认，原地左转90度，然后以转向完成时的当前视野为准，飞到前方可见的第二栋高楼旁边并悬停确认，最后原地右转90度。
```
