# 模型部署与启动命令

服务器 4× RTX 3080 Ti，所有模型均以 OpenAI `/v1` 兼容 API 对外服务。

---

## 资源分配总览

| GPU | 端口 | 模型 | 用途 |
|-----|------|------|------|
| 0+1 | `:8004` | Qwen2.5-VL-7B (3DG-VLN) | **轨迹规划**（视觉+文本→waypoint 序列） |
| 2 | `:8003` | GroundingDINO | **目标检测**（图+英文目标名→bbox） |
| 3 | `:8000` | Qwen2.5-7B-AWQ (vLLM) | **任务解析**（自然语言→结构化任务阶段） |
| 3 | `:8001` | Qwen3-VL-4B-Instruct | **目标检测-VLM模式**（备选，性能不及 GroundingDINO） |

---

## 1. GroundingDINO —— 目标检测（:8003）

**用途**：接收前视/下视图像 + 英文目标描述（如 `"red car"`），返回目标 bbox 坐标。是整个导航闭环中"找到目标在哪"的核心模块。

**启动命令**：

```bash
CUDA_VISIBLE_DEVICES=2 python groundingdino_server.py
```

> 非标准 OpenAI 格式，接口为 `POST :8003/detect`。依赖 `groundingdino` 库本地推理。

---

## 2. Qwen2.5-VL-7B (3DG-VLN) —— 轨迹规划（:8004）

**用途**：接收双视图（前视+下视）+ 任务指令 → 输出 5 个 body-frame waypoint `[[dx,dy,dz], ...]`。这是 3DG-VLN 论文的模型，Uni-LaViRA 用其作为规划器（planner）。

**启动方式（二选一）**：

### 方式 A：vLLM 部署（推荐，高吞吐）

```bash
# 先合并 LoRA（如果是微调后的模型）
llamafactory-cli export \
    --model_name_or_path /data/sakura/models/3DG-VLN \
    --adapter_name_or_path ./output/qwen2_5vl_7b_3dgvln_lora/checkpoint-best \
    --template qwen2_vl \
    --finetuning_type lora \
    --export_dir /data/sakura/models/3DG-VLN-merged

# vLLM 启动
CUDA_VISIBLE_DEVICES=0,1 vllm serve /data/sakura/models/3DG-VLN-merged \
    --port 8004 --max-model-len 8192
```

### 方式 B：Flask Server（开发调试用）

```bash
CUDA_VISIBLE_DEVICES=0,1 python qwen_server_updated.py
```

> `qwen_server_updated.py` 直接加载 HuggingFace 模型，支持 `/v1/chat/completions`。首次请求慢（模型加载），后续快。

---

## 3. Qwen2.5-7B-AWQ —— 任务解析（:8000）

**用途**：将用户的中文自然语言指令（如"飞到红色汽车旁边，再飞到白房子上面"）解析为结构化的多阶段任务（`[{instruction: "Fly to the red car", mode: "target", ...}]`）。

vLLM 启动（AWQ 量化模型，12GB 单卡可跑）：

```bash
CUDA_VISIBLE_DEVICES=3 vllm serve /data/sakura/models/Qwen2.5-7B-Instruct-AWQ \
  --host 0.0.0.0 --port 8000 \
  --max-model-len 4096

```

---

## 4. Qwen3-VL-4B-Instruct —— VLM 目标检测（:8001，备选）

**用途**：当不使用 GroundingDINO 时，用 VLM 做目标检测。精度不如 GroundingDINO，但不需要额外 GPU 和 库。

```bash
  CUDA_VISIBLE_DEVICES=3 vllm serve /data/sakura/models/Qwen3-VL-4B-Instruct \
  --host 0.0.0.0 --port 8000 \
  --max-model-len 4096
```

> 注意：和 Qwen2.5-7B-AWQ 共用 GPU3（显存足够，7B AWQ ≈ 4.5GB + 4B ≈ 4GB = 8.5GB < 12GB），但不能同时跑端口 8000 和 8001，需选其一。

---

## 5. 3DG-VLN 微调模型 —— LoRA checkpoint 部署

微调完成后，合并 LoRA 再部署：

```bash
conda activate llama-factory
llamafactory-cli export \
    --model_name_or_path /data/sakura/models/3DG-VLN \
    --adapter_name_or_path ./output/qwen2_5vl_7b_3dgvln_lora/checkpoint-1500 \
    --template qwen2_vl \
    --finetuning_type lora \
    --export_dir /data/sakura/models/3DG-VLN-finetuned

# 切换到 vlm 环境
conda activate vlm
CUDA_VISIBLE_DEVICES=0,1 vllm serve /data/sakura/models/3DG-VLN-finetuned \
    --port 8004 --max-model-len 8192
```

## 数据流总览

```
用户指令 (中文)
    │
    ▼
┌─ Qwen2.5-7B-AWQ (:8000) ─┐
│  任务解析                  │
│  "飞到红色汽车旁边..."        │
│  → [{target: "red car",      │
│      mode: "target", ...}]   │
└────────────┬───────────────┘
             │ target (英文)
             ▼
┌─ GroundingDINO (:8003) ───┐
│  目标检测                   │
│  front_img + "red car"      │
│  → bbox [x1,y1,x2,y2] +    │
│    depth_meters             │
└────────────┬───────────────┘
             │ bbox + depth + direction
             ▼
┌─ Qwen2.5-VL-7B (:8004) ───┐
│  轨迹规划                   │
│  front+down img + instr     │
│  → [[dx,dy,dz], ...] ×5    │
└────────────┬───────────────┘
             │ waypoints (机体坐标系)
             ▼
┌─ AirSim Executor ──────────┐
│  执行飞行 + 下一帧图像       │
└────────────────────────────┘
```

## 一次性全部启动

```bash
# 终端1: GroundingDINO
CUDA_VISIBLE_DEVICES=2 python /data/sakura/models/GroundingDINO/groundingdino_server.py

# 终端2: 任务解析
CUDA_VISIBLE_DEVICES=3 vllm serve /data/sakura/models/Qwen2.5-7B-Instruct-AWQ --host 0.0.0.0 --port 8000 --max-model-len 4096

# 终端3: 轨迹规划（选一个）
# vLLM 方式:
CUDA_VISIBLE_DEVICES=0,1 vllm serve /data/sakura/models/3DG-VLN-merged --host 0.0.0.0 --port 8004 --max-model-len 8192
# Flask 方式:
CUDA_VISIBLE_DEVICES=0,1 python qwen_server_updated.py
```
