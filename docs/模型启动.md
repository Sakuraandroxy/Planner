# 模型启动

更新时间：2026-07-15。

> 本文档已按当前 AirSim UAV-VLN 主线刷新。当前在线入口是 `run_airsim_web.py`，配置入口是 `config/default.yaml`，离线评测入口是 `eval/run_eval.py`。

## 推荐部署

Windows 本机运行 AirSim 和 Web；Linux 服务器运行模型服务。

```text
Windows: run_airsim_web.py + AirSim + Dashboard
Linux: parser :8000, GroundingDINO :8003, Qwen planner :8004
```

## 启动顺序

1. 启动 GroundingDINO。
2. 启动任务解析模型。
3. 启动 Qwen planner。
4. 启动 AirSim/UE。
5. 本机运行 `python run_airsim_web.py`。

## 常见端口

| 服务 | 默认 |
|---|---|
| AirSim RPC | `41451` |
| Dashboard | `5000` |
| task parser | `8000` |
| GroundingDINO | `8003` |
| Qwen planner | `8004` |

## 安全

不要提交 API key、SSH key、模型 checkpoint 或服务器凭据。
