# 上下文管理技术流程

更新时间：2026-07-15。

> 本文档已按当前 AirSim UAV-VLN 主线刷新。当前在线入口是 `run_airsim_web.py`，配置入口是 `config/default.yaml`，离线评测入口是 `eval/run_eval.py`。

## 当前默认链路

| 功能 | 当前默认 | 位置 |
|---|---|---|
| 任务解析 | `vlm_parser` | `agent/task_parser/vlm_task_parser.py` |
| 目标检测 | `groundingdino` | `agent/detector/groundingdino_detector.py` |
| 轨迹规划 | `qwen_planner` | `agent/planner/qwen_planner.py` |
| 完成判定 | `depth_detector` | `agent/completion/task_completion.py` |
| 候选轨迹 | `smooth_bridge` | `agent/candidate/` |
| 世界模型 | 默认关闭 | `agent/world_model/` |
| 重定位 | 默认关闭 | `agent/relocalization/` |
| 轨迹精修 | 默认关闭 | `agent/trajectory_refiner.py` |
| 碰撞恢复 | 默认开启，仅后退 | `agent/collision_recovery.py` |

## 在线闭环流程

```text
用户任务
  -> VLM task parser 拆成 action/detect/target 阶段
  -> action 阶段直接执行
  -> target 阶段抓 front/down RGB
  -> RGB 到手后并行启动 GroundingDINO 检测和 Qwen 规划
  -> depth 返回后计算目标框深度
  -> VLM 完成判定输出 target_detected/done/accepted_view
  -> 未完成则生成候选轨迹并执行
  -> 完成则进入下一阶段
```

## 当前关键配置

```yaml
AGENT.PLANNER: qwen_planner

TASK_COMPLETION.NAME: depth_detector
TASK_COMPLETION.CALL_MODE: parallel_preplan

CANDIDATE.ENABLED: true
CANDIDATE.MODE: smooth_bridge
WORLD_MODEL.ENABLED: false
RELOCALIZATION.ENABLED: false
TRAJECTORY_REFINER.ENABLED: false
COLLISION_RECOVERY.ENABLED: true
```
