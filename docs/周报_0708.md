## 2. 关键问题

### 2.1 微调模型输出 dz 异常——无人机钻地

**现象**：Step 1 输出 waypoint `[dx≈1~6, dz≈0.3~4.5]`，world z 从 -1.7 到 -1.8（正常）。Step 2 输出 `dz≈1~5`，world z 从 -1.8 到 3.1，NED 下正 z=向下，无人机直钻地面。

**根因分析**：

1. **训练数据自带地形起伏**：3DG-VLN 数据集在 TravelUAV 有地形变化的 UE 地图上采集，`extract_training_samples.py` 计算的 body-frame waypoint 保留了真实轨迹的 dz 变化。模型忠实地学到了"飞越远 dz 越大"的模式。

2. **512² 视觉退化**：为适配 12GB 显存降分辨率，vision token 从 5300→1336，VLM 视觉能力下降，退化为凭文本统计输出（dx 大→dz 大）。

3. **不是坐标转换 bug**：body→world 转换正确（`rot_3d @ local + pos`），dz 符号在 NED 下语义一致。问题在模型输出的**pattern 本身**是错误的。

| 环节 | 是否正常 |
|------|---------|
| 训练数据提取 | dz 保留真实地形变化（非 bug，是设计选择） |
| 训练收敛 | loss 正常下降 |
| 模型推理 | **dz 输出偏离平坦地形预期** |
| 坐标转换（body→world） | 正确 |
| AirSim 执行 | 正确 |

### 2.2 4卡部署显存边缘

- ZeRO-3 + offload_param=none + 1024² → OOM（cross_entropy 1.65GB 分配失败）
- ZeRO-3 + offload_param=none + 512² → 勉强运行，GPU 3 显存 93%，频繁 cache flush
- vLLM 部署需 `--tensor-parallel-size 2`，单卡 12GB 装不下 7B
