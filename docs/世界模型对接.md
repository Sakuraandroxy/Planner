# 世界模型对接

> 世界模型运行在独立主机上，通过 Flask HTTP API 对 K 条候选轨迹打分，返回最优轨迹下标。

---

## 一、架构

```
┌─ Uni-LaViRA (本项目) ─────────────────────────┐
│                                                │
│  planner.plan() → K 条候选                      │
│       │                                        │
│       ▼                                        │
│  ApiWorldModel.score()                         │
│       │  POST {front, down, instruction,        │
│       │         candidates: [{waypoints}, ...]}  │
│       ▼                                        │
│  ┌─────────────────────────────┐                │
│  │  世界模型服务 (独立主机)      │                │
│  │  Flask @app.route('/score') │                │
│  │  对每条候选打分 → best_index │                │
│  └─────────────────────────────┘                │
│       │                                        │
│       ▼                                        │
│  使用 best_index 选最优候选 → 执行               │
└────────────────────────────────────────────────┘
```

## 二、HTTP 接口定义

### 请求

```
POST http://host:5001/score
Content-Type: application/json

{
    "front_image": "<JPEG base64>",
    "down_image": "<JPEG base64>",
    "instruction": "Fly to the red car",
    "candidates": [
        {
            "waypoints": [[5.0, 0.0, 0.0], [10.0, -2.0, 0.0], ...],
            "actions": ["forward 5", "left 10", ...],
            "reason": "直行接近目标",
            "delta": [30.0, 0.0, 0.0, 0.0],
            "scale": 1.0
        },
        ...
    ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `front_image` | string | 前视图 JPEG base64 |
| `down_image` | string | 下视图 JPEG base64 |
| `instruction` | string | 英文任务指令 |
| `candidates[].waypoints` | [[dx,dy,dz], ...] | 机体坐标 waypoints（相对起始位置） |
| `candidates[].actions` | [string] | 原始原子动作（如 `["forward 5", "left 10"]`） |
| `candidates[].reason` | string | 规划器给出的选择理由 |
| `candidates[].delta` | [dx,dy,dz,dphi] | 该候选的 net 位移（世界模型可能用于快速判断方向） |
| `candidates[].scale` | float | 候选的置信度（1.0 = 正常） |

### 响应

```json
{
    "best_index": 0,
    "scores": [0.85, 0.42, 0.91],
    "reasoning": "候选0路径最短且无碰撞风险"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `best_index` | int | 最优轨迹下标（0-based） |
| `scores` | [float] | 每条候选的分数（可选，用于调试） |
| `reasoning` | string | 选择理由（可选） |

## 三、本项目使用方式

### 3.1 配置

```yaml
# config/default.yaml
WORLD_MODEL:
  ENABLED: true                           # 启用世界模型
  NAME: api_world_model                   # 实现名
  URL: http://172.27.143.102:5001/score  # 世界模型服务地址
  TIMEOUT: 30                             # 请求超时(秒)
```

### 3.2 代码调用

```python
from agent.world_model import build_world_model

wm = build_world_model()
if wm:
    result = wm.score_from_pil(
        front_img, down_img, instruction, candidates
    )
    best = candidates[result.best_index]
    client.execute_waypoints(best["waypoints"])
```

### 3.3 在 run_airsim_web.py 中的集成点

世界模型在 `planner.plan()` 之后、`execute_waypoints()` 之前调用：

```python
# 4. 规划
result = planner.plan(front, down, instruction, ...)

# 5. 世界模型打分（可选）
if result.candidates and len(result.candidates) > 1:
    wm = build_world_model()
    if wm:
        wm_result = wm.score_from_pil(front, down, instruction, result.candidates)
        best_candidate = result.candidates[wm_result.best_index]
        # 更新 waypoints 为最优候选的 waypoints
        result.waypoints = best_candidate["waypoints"]

# 6. 执行
client.execute_waypoints(result.waypoints)
```

## 四、世界模型服务端参考实现

```python
# server.py (运行在独立主机上)
from flask import Flask, request, jsonify
import numpy as np

app = Flask(__name__)

@app.route('/score', methods=['POST'])
def score():
    data = request.json
    candidates = data['candidates']
    
    scores = []
    for c in candidates:
        waypoints = c['waypoints']
        # 示例打分逻辑：路径越短分数越高
        path_length = sum(
            np.linalg.norm(np.array(waypoints[i]) - np.array(waypoints[i-1]))
            for i in range(1, len(waypoints))
        ) if len(waypoints) > 1 else 0
        score = 1.0 / (1.0 + path_length)  # 简化版
        scores.append(float(score))
    
    best_index = int(np.argmax(scores))
    return jsonify({
        "best_index": best_index,
        "scores": scores,
        "reasoning": f"selected candidate {best_index}"
    })

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5001)
```

## 五、数据流

```
K 条候选轨迹 (来自 api_atomic_planner):
  每条: {actions, reason, delta}
    ↓
  _actions_to_body_waypoints(actions) → waypoints [[dx,dy,dz], ...]
    ↓
  POST /score {front, down, instruction, candidates: [{waypoints, actions, reason, delta}]}
    ↓
  世界模型返回 {best_index, scores}
    ↓
  execute_waypoints(candidates[best_index]["waypoints"])
```

## 六、关键设计决策

| 决策 | 理由 |
|------|------|
| waypoints 在客户端计算 | 世界模型不依赖具体的动作解析逻辑，只接收统一的 waypoints |
| 候选含原始 actions | 世界模型如果需要理解动作语义可以参考 |
| delta 预计算 | net 位移让世界模型快速判断候选的整体方向，不用遍历 waypoints |
| 不阻塞执行 | 超时/连接失败时回退到 selected_index=0（规划器自己选的） |
