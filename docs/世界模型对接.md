# 世界模型对接

更新时间：2026-07-15。

> 本文档已按当前 AirSim UAV-VLN 主线刷新。当前在线入口是 `run_airsim_web.py`，配置入口是 `config/default.yaml`，离线评测入口是 `eval/run_eval.py`。

## 当前状态

世界模型是可选轨迹打分服务，默认关闭。

```yaml
WORLD_MODEL:
  ENABLED: false
  NAME: api_world_model
  URL: http://127.0.0.1:5001/score
```

## 接入点

```text
Qwen planner -> candidate generation -> pre-score top-k -> optional world model -> execute selected trajectory
```

## 请求内容

- front image
- down image
- instruction
- top-k candidate waypoints

## 响应内容

```json
{"best_index": 0, "scores": [0.8, 0.7], "reason": "..."}
```

世界模型只影响轨迹选择，不影响完成判定。
