# 滑动窗口轨迹规划与世界模型接入

更新时间：2026-07-15。

> 本文档已按当前 AirSim UAV-VLN 主线刷新。当前在线入口是 `run_airsim_web.py`，配置入口是 `config/default.yaml`，离线评测入口是 `eval/run_eval.py`。

## 平滑桥候选轨迹

当前默认 `CANDIDATE.MODE=smooth_bridge`。

过程：

1. 在原始 waypoint 前加入隐式起点 `[0,0,0]`。
2. 固定终点，扰动中间点。
3. 用指数核协方差生成相邻相关的平滑噪声。
4. 横向和竖向噪声分别控制。
5. 过滤过大转角、过长路径和明显后退。
6. 计算预打分并排序。

## 预打分

预打分衡量轨迹本身质量，不等于检测置信度。主要看 progress、alignment、safety、smoothness。

## 世界模型

开启世界模型后，把 top-k 候选交给外部服务二次打分；默认关闭时选择预打分最高项。
