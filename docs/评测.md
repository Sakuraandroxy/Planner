# 评测

更新时间：2026-07-15。

> 本文档已按当前 AirSim UAV-VLN 主线刷新。当前在线入口是 `run_airsim_web.py`，配置入口是 `config/default.yaml`，离线评测入口是 `eval/run_eval.py`。

## 入口

```bat
python eval/run_eval.py ^
  --dataset E:\AGPReID\data\UAV-VLN-FOV-DATA\test\test ^
  --env_root /data/sakura/data/TravelUAV_env ^
  --gpu 2
```

`--gpu 2` 通常表示远端 UE4 使用第三张显卡，对应 `-GraphicsAdapter=2`。

## 流程

1. 扫描数据集 scene 和 episode。
2. 按 scene 启动对应 TravelUAV UE4 环境。
3. 可选建立 SSH tunnel 到本机 `localhost:41451`。
4. 设置 episode 起始位姿。
5. 调用与在线一致的 parser/completion/planner/execution 流程。
6. 用数据集 GT 目标坐标计算 NE/SR/OSR/SPL。

## 指标

| 指标 | 含义 |
|---|---|
| NE | 最终位置到 GT 目标的距离 |
| SR | NE 小于成功半径 |
| OSR | 过程中曾进入成功半径 |
| SPL | 成功加权路径效率 |
| TL | 实际路径长度 |
| SL | 起点到目标直线距离 |

## 在线与离线区别

在线 Web 指标使用视觉估计目标位置，只能调试。离线评测使用 GT，适合汇报和论文对比。
