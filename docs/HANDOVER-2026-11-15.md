## 4 下一步：UE4 子进程入口（控制台飞 UE4 前的唯一大块）

主进程不得加载 AirSim 客户端（`tests/test_architecture.py`），而 `ThreadedMissionWorker`
跑在 HTTP 进程里，所以 UE4 会话现在只能像验证脚本那样直接构造。

动手前先把旧分支读明白，别从头设一套：

```bash
git show origin/low-altitude-level-view-visual-goal-navigation:planner/server_worker.py
git show origin/low-altitude-level-view-visual-goal-navigation:planner/ports/backend_runtime.py
```

已经记过两次的坑：旧 worker 的 IPC 只认 `task` 与 `shutdown` 两条命令；心跳重连与
停止接管在旧 `ServerController` 里，不在 worker 协议中。只看 worker 接口会漏掉后半部分。

另有一条已知降级：UE5 的 `streaming-view` 四机位标定在本机四帧打分完全相同，于是回落
内置顺序——标定期间世界暂停、`idle_tick` 还没跑。不阻断任务，但循环顺序在本机没被实测标定过。
