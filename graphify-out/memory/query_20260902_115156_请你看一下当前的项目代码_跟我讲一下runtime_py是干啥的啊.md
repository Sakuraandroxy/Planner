# Q: 请你看一下当前的项目代码，跟我讲一下runtime.py是干啥的啊

## Answer

Expanded from original query via graph vocab: runtime, run, loop, stage, planning, controller, capture, target, memory, completion, path, streaming. runtime.py 是快慢双系统的总调度器，不是单独的规划模型或 AirSim 驱动。它通过 RuntimeObjects 创建并汇集检测器、任务管理器、MissionMemory、Qwen 滑窗规划器、FastSlowController、CompletionPipeline、避障、重定位和碰撞恢复组件。run_fast_slow_loop 解析任务并拆分阶段，进入新阶段时清理旧队列、预绑定目标或建立视角相对绑定；随后在快速循环中读取位姿、消费路径进度、检查碰撞、目标距离、任务完成和目标丢失，同时按需异步提交慢速 Qwen 规划。规划结果返回后，runtime.py 负责坐标转换、目标记忆约束、避障、above 高度与屋顶约束、到达点截断，再由 controller 管理队列，由 ContinuousPathStream 下发 AirSim 连续路径。run_fast_slow_web 负责启动 Web、AirSim、后台相机和录像后调用同一主循环。简而言之，它决定各功能何时运行、结果是否仍有效以及无人机下一步继续飞、停车、重规划、重定位还是完成当前阶段。
